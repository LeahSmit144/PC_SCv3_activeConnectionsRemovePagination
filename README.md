# PC_SCv3_activeConnectionsRemovePaginations
Restyle Pheonix Contact Secure Cloud version 3 active connections page to remove pagination in favor of a scrollable list with search bar functionality.

Steps:
* 1. Install the ViolentMonkey browser add-on to run the script. https://violentmonkey.github.io/get-it/
* 2. Click on the newly added ViolentMonkey add-on. 
    - 2a. If your browser prompts you to enable "Allow User Scripts" or similar, then follow the steps in this browser prompt.
    - 2b. Click the settings cog wheel to navigate to the ViolentMonkey settings page.
    - 2c. Click the add plus sign and select 'New' to create a new ViolentMonkey script.
    - 2d. Overwrite the contents of the 'activeConnectionsStyling.js' file into the newly created ViolentMonkey script.
    - 2e. Click 'Save & Close' in the top right.
    - 2f. Reload the https://secure.phoenixcontact.cloud/activeconnections.php page to enable the script.
